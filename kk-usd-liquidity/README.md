# 美元流动性看板

生成和更新独立 HTML 看板，集中查看美元融资成本、金融压力与财政现金变化，支持历史图、日度摘要和指标历史 Excel 导出。

## 核心逻辑

参考程坦关于美元流动性的课程，以资产负债表为起点，先问清楚：**谁向谁融资、通过什么工具、成本和约束发生了什么变化。**据此分层观察：

1. **先看广义环境。** 用美元、实际利率、信用利差和波动率，判断风险资产面临的融资与贴现环境，并结合 OFR 金融压力指数交叉检查。
2. **再定位融资压力。** 将 SOFR 等市场利率与政策利率对照，结合成交量、准备金和银行存款，识别资金供给与中介机构约束。月末、季末、缴税和国债结算会带来短期扰动，需要检查持续性。
3. **最后看外溢与应对。** 观察压力是否扩散到信用和汇率市场，以及 SRF、贴现窗口、美元互换等后备工具的使用情况。局部融资波动对风险资产的影响，取决于传导范围、持续时间和政策响应。

看板按环节展示证据，保留各指标含义，不机械合成为单一“净流动性”分数。

## 跟踪哪些指标

主体包含6类、33个唯一指标；广义美元指数在两个模块中重复展示。

| 模块 | 指标 |
|---|---|
| 政策利率与美债定价 | 联邦基金目标区间、EFFR、IORB，美国2年、5年、10年期国债收益率 |
| 广义金融条件 | OFR金融压力指数、标普500、广义美元指数、10年期TIPS实际利率、高收益债OAS、VIX、布伦特原油 |
| 在岸担保融资 | SOFR、ON RRP报价利率、SOFR与ON RRP利差、TGCR、SOFR成交量 |
| 在岸信用与银行 | 商业票据信用评级利差、准备金余额、小银行存款、小银行现金资产占比、SRF接受量、贴现窗口一级信贷 |
| 离岸美元 | 广义美元指数、欧元兑美元、美元兑日元、美元兑人民币、美元央行流动性互换余额、FIMA Repo余额 |
| 财政与美债供给 | 市场化国债5日净发行、TGA日终余额、联邦公共债务总额、联邦政府净值 |

另附中美10年期国债利差、下一次美联储议息概率和官方事件日历。议息概率采用 Polymarket 市场报价。

## 口径与使用

- SOFR与ON RRP利差按同日数据计算。ON RRP报价利率与工具使用余额分别解释；本版跟踪报价利率。
- 商业票据采用A2/P2与AA非金融企业的30日利差。离岸模块通过汇率和官方后备工具提供线索，尚未纳入货币互换基差，判断时需补充相应证据。
- 官方工具用量上升可能同时反映压力和政策支持；TGA、债务存量及政府净值需结合资金来源、期限和统计口径解释。
- 公开数据主要来自 FRED、OFR、美国财政部与美联储。布伦特和中美利差需自行配置 Choice 授权，未启用时保留缺项。

需要 Node.js 22+。完整安装、更新命令见 [Skill说明](SKILL.md)，指标定义与计算见 [数据合同](references/data-contract.md)。各项保留实际观察日和缺失状态，供研究跟踪使用。
