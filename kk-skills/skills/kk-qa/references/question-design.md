# 问题与答案的设计

## 问题类型

每类问题对应论证中的一项任务。通常混合动作、因果和边界三类，以覆盖方法、理由及限制。

| 类型 | 关注点 | 示例 |
|------|------|------|
| 动作 | 作者怎样完成关键步骤 | 他怎么把 X 转成 Y？ |
| 因果 | 方法为什么成立 | 这一步凭什么有效？ |
| 边界 | 方法在什么条件下失效 | 数据稀疏时还有效吗？ |
| 比较 | 用户要求比较的方案差异 | 两种做法的代价差在哪？ |

比较型问题仅在用户明确要求比较时使用。每个问题均应能从材料中取得论据。

## 问题的措辞

直接问具体的动作、原因或条件，尽量在 20 字以内说清。避免只有定义、步骤数量、抽象评价或空泛展望的问题。

可采用以下写法：

- 钱花在哪一步才划算？
- 作者怎样验证这个解释？
- 结论依赖哪些前提？
- 这套办法在哪一步失效？

标题后用一句话交代切入点。后续问题还应说明它怎样承接前面的判断，让读者能够跟上推理。

## 答案的三段

```markdown
**结论**：一句能够独立读懂的判断。

**形式化**：一行表示关系的文字与简单符号。

**怎么想到的**：2-4 条论证步骤，每条推进一步。
```

### 结论

写清对象、动作和判断。读者单独摘出这句话，也应当知道作者说了什么。

例如，在原文有相应依据时，可以写：「每轮检验都能指出具体错误，下一轮修改才有明确方向。」

避免「多个维度上都有一定优势」等难以核对的评价。

### 形式化

用文字和简单符号压缩关系，单独读这一行也应大致明白意思。允许 `=`、`→`、`←`、`+` 等基础符号，避免复杂公式和 LaTeX。

| 模式 | 示例 | 用途 |
|------|------|------|
| 角色 | `协调者 = 拆分任务 + 汇总结果` | 说明分工 |
| 流向 | `证据 → 判断 → 结论` | 展示论证顺序 |
| 递进 | `尝试 → 检验 → 修改` | 展示逐步推进 |
| 比较 | `方案 A：并行探索；方案 B：逐步验证` | 回答用户明确提出的比较要求 |

这些示例用于说明写法，实际关系须以原文为准。定性材料使用定性关系，不加入未经验证的数量、概率或大小判断。

### 论证步骤

每条只推进一步，明确前一步为什么能够支持下一步。可用「首先」「因为」「因此」「在这个前提下」等连接词，但应选用与实际逻辑相符的关系。

例如，原文有相应依据时：

- 首先，研究者按已知标准检查本轮结果，找出具体错误。
- 有了这些错误记录，下一轮可以针对出错环节修改。
- 因此，在标准稳定且反馈有效时，多轮修改有机会提高结果质量。

原文只给出相关性时，保留相关性表述；缺少证据的推断明确标注。

论证涉及适用条件时，在相应步骤中写清结论成立需要什么条件，以及材料覆盖到哪里。

- 原文给出了失效情形，就说明具体情形及其原因。
- 原文仅在某类样本中验证，就写明样本范围。
- 原文未讨论某项条件，就说明「原文未验证该条件」。

条件说明应具体，也不要自行添加作者未报告的实验结论。

## 问答链的顺序

先确认核心问题，再沿着依赖关系安排实现方式、证据、代价与边界。论证允许分支：两个问题可以共同承接一个前提，但需要说清各自追问的方向。

不必把内部结构草稿另存为文件。直接用前后承接的问答，让读者理解作者的推导过程。

## 数量与覆盖

题数由材料的论证结构和实际覆盖需要决定，不预设固定题数、范围或上限。问题尽量在 20 字以内。

- **拆分**：每问聚焦一个可独立解释的论证任务。同一答案需要分别解释不同机制、论据或适用条件，且合在一起会省略关键推理时，拆成有承接的问题。
- **合并**：仅合并论证任务相同、内容实质重复的问题。一个论点所需的多个证据可以放在同一答案中，保留它们与结论之间的推导关系。
- **完成条件**：逐项对照原文，确认核心论点、关键转折、重要分支、关键论据及适用条件均有对应问答，再检查重复内容和缺少依据的问题。覆盖核对通过后结束提取。
- **长材料**：按主题分组，各组分别核对覆盖，题数仍由实际内容决定。如受单次输出限制，分批交付，并标明当前覆盖范围及尚未展开的主题。
- **用户指定题数**：遵从用户明确提出的数量要求；若因此需要取舍，说明覆盖范围。

## 自检

- [ ] 每个问题都值得展开解释。
- [ ] 每个答案有结论、形式化和论证步骤。
- [ ] 结论单独阅读也能理解。
- [ ] 形式化准确表达原文关系。
- [ ] 每条论证只推进一步，因果和补充关系说清楚。
- [ ] 论证涉及的适用条件具体，证据缺口已说明。
- [ ] 问题的承接自然，必要的连接句齐全。
- [ ] 问题类型覆盖方法、理由及限制；已对照原文逐项确认核心论点、关键转折和重要分支均有对应问答。
- [ ] 每句中文读起来顺口，定语不过度叠加，术语有具体解释。
- [ ] 默认结果直接在对话框输出；用户明确要求保存后才生成文档。
