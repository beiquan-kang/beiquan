# 指标定义与数据契约

## 日期与计算

最近完整周为周一至周日；周末收盘是该周香港最后实际交易日。周涨跌基于前周最后有效收盘；报告周无值时保留缺失，不用更早一周代替。金额周合计与日均成交额要求周内所有应有交易日到齐。月度指标用最新两个月差，不能写周变化。海外资金保留周三等原始统计日，按ISO周归属。

百分比尺度输入以百分数水平存储，如4.84表示4.84%；差值pp＝本期－前期。价格／金额相对变动%＝（本期÷前期－1）×100。前值为0时相对变动留空。净流量变化采用金额差，允许负值和0；缺失保持null。

## 固定年度盈利修正

名称为“中国股票指数2027年盈利预期修正——固定篮子研究模拟”。三系列为恒生科技、MSCI中国、恒生中国企业。2026-03-31共同基准归零，目标2027日历年，180天一致预期窗口。

指数盈利E(t)＝Σ［冻结持股数×该证券2027年度EPS(t)×冻结汇率×股份单位换算系数］。修正＝［E(t)÷E(2026-03-31)－1］×100。跨指数证券去重仅用于请求，持仓仍按各指数独立计算。保留亏损。冻结样本、股数、基准EPS、汇率及元数据均需用户授权取得；新安装没有这些资料时不复制他人的底表，不默认用当前成分重建旧基准。

阿里巴巴CY2027＝25% FY2027＋75% FY2028。币种、ADR／普通股、每手与每股单位须一致；拆合股等变更需核对生效日及供应商EPS是否追溯换算。现金分红复权不能替代股份单位换算。任一必需EPS、币种、财年、股份检查失败时该指数当期留空，不能缩减样本以凑数。迁移预测年度需另建版本并重新取基准分母，不能自动滚动年度。

完整历史限制保存在数据档案。若只有最近历史周有效，可展示“最近有效周变化（起止日）”；不得标成报告周变化。正文盈利句也需明确“最近有效周”。

## normalized.json

```json
{
  "week": "2026-W45",
  "market_end": "2026-11-06",
  "previous_close": "2026-10-30",
  "calendar": ["2026-10-30", "2026-11-02", "2026-11-03", "2026-11-04", "2026-11-05", "2026-11-06"],
  "indicators": {
    "hsi": {
      "name": "恒生指数",
      "unit": "点",
      "frequency": "daily",
      "change_kind": "pct",
      "aggregation": "last",
      "source": "授权行情渠道及字段",
      "rows": []
    }
  },
  "earnings": [],
  "summary": {"headline": "", "market": "", "flows": "", "rates": "", "footnote": ""}
}
```

此处空rows仅说明schema，不作为生产数据。calendar须覆盖所展示历史及前周、本周真实交易日。rows条目为`{"date":"YYYY-MM-DD","value":数值或null}`，同指标日期唯一，按日期排序，数值有限。frequency取daily、weekly、monthly；change_kind取pct、pp、absolute；aggregation取last、mean、sum。weekly表示已正确汇总的周数据，不能再求和；foreign以实际统计日入表。

earnings条目为`{"name":"指数名称","source":"授权来源及固定篮子版本","rows":[...]}`，value已是共同基准修正百分数。来源、单位、历史版本及请求证据保存在项目目录，不向页面塞来源附录。
