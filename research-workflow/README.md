# KK 研究工作流

这里分享我在资料管理和 AI 辅助研究中的实践，包含两个 Skill 与一篇设计说明。

## 内容

| 文件 | 用途 |
|---|---|
| [kk-knowledge-base](skills/kk-knowledge-base/SKILL.md) | 资料入库、原文检索、可阅读归档与结果验收 |
| [kk-research](skills/kk-research/SKILL.md) | 独立研究、角色分工、证据补充和实际输入披露 |
| [设计思路](设计思路草稿.md) | 为什么这样设计，以及两部分如何配合 |

## 从哪里开始

建议先阅读设计思路，再查看两个 Skill 的规则。Skill 使用 Agent Skills 的目录和 YAML 格式，每个文件夹包含一个 SKILL.md。

## 使用准备与交付范围

当前公开内容为 Skill 规则和设计说明，不包含配套运行代码。

- kk-knowledge-base 依赖已配置的 AnythingLLM Desktop、Ollama 与知识库客户端。
- kk-research 完整运行依赖 Hermes 的 clean-research 插件、独立模型调用、会话管理和取证客户端。
- 部署时须配置自己的路径、工作区和凭据，并核对客户端命令。
- /kk-research 是公开入口命名，插件路由需要同步适配；下载文件不会自动注册命令。
- 资料解析、嵌入与存储在本机完成；选中的原文会发送给分析模型服务商。使用者自行确认发送授权。

公开文件经过格式和内容检查，新环境的入库、检索与上下文隔离仍需实际验收。配套代码将在另行整理、审查后决定发布范围。
