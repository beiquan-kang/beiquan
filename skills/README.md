# Skills

每个子目录是一项独立的 Skill，包含技能说明及所需的脚本、参考资料和资源。

| 技能 | 用途 |
|---|---|
| [综合投研周报](kk-week/README.md) | 宏观、港股、A股板块、A股策略及美元流动性周报 |
| [美元流动性跟踪](kk-usd-liquidity/README.md) | 美元融资、金融条件和财政现金看板 |
| [个人知识库](kk-knowledge-base/SKILL.md) | 资料入库、原文检索与归档 |
| [独立研究](kk-research/SKILL.md) | 研究分工、证据补充与输入披露 |
| [结构深读](kk-structural-reading/SKILL.md) | 还原核心答案、论证推进与原文位置 |
| [会议纪要](kk-hyjy/SKILL.md) | 音视频转写、纪要、逐字稿与会议实录 |

## 安装

将需要的技能文件夹完整复制到应用配置的技能目录，保留其子目录。Hermes使用当前配置档的 `skills/` 目录。各技能的环境要求、授权和交付范围以其说明为准。

会议纪要建议同时安装结构深读。详见[阅读与会议整理安装说明](../articles/reading-meetings/README.md)、[研究工作流说明](../articles/research-workflow/README.md)。

## 许可

各技能分别遵循原有许可声明。阅读与会议整理的MIT许可及来源声明保留在[原发布说明](../articles/reading-meetings/README.md)中；其余技能的许可按各自文档说明处理。
