# 美元流动性

用随包模板生成可直接打开的独立网页。保留6类指标、33个唯一指标、中美10年期国债利差、下一次美联储议息概率及官方事件日历。图表支持区间切换、悬停、导航、口径折叠和指标历史 Excel 导出。

## 创建与更新

需要 Node.js 22 或以上版本。页面与公开数据流程只依赖 Node.js 内置模块。首次执行前检查 `node --version`。

根据用户指定位置选择输出目录，遵循其保存偏好；所有数据、网页与运行记录均写在这个项目目录内。`<SKILL_DIR>` 指本文件所在目录，`<OUTPUT_DIR>` 指新项目的空目录。

```text
node "<SKILL_DIR>/scripts/create-dashboard.mjs" "<OUTPUT_DIR>"
```

此命令仅建立页面与数据合同，初始指标全部留空。需要实际数据时，接着在生成的项目目录执行：

```text
node scripts/update.mjs
node scripts/verify.mjs
```

更新命令默认使用北京时间今天，也可传入一个有效的 `YYYY-MM-DD`。指标保留不晚于指定日的源端观察值。议息概率与未来事件按本次抓取时间采集，不能将其解释为历史时点所知信息。已发布的检查日不能向前覆盖；需要历史截面时另建项目目录。

输出为 `dist/index.html`，其中内嵌数据、样式和脚本，支持本地直接打开，也可作为静态网页托管。`dist/publication-status.json` 记录完整性、缺项、原观察日期和文件哈希。

对已有项目先运行 `node scripts/verify.mjs`，再按用户要求更新。只调整页面或重新构建时使用 `node scripts/build.mjs`。模板是只读来源；后续工作应在生成的项目中进行。

## 数据来源与可选授权

公开数据来自 FRED、OFR、美国财政部、美联储、BEA、BLS 和 Polymarket。它们按各自发布频率刷新。某个来源失败时，其他可用数据继续发布；历史值显示原观察日期与本轮未更新，首次缺失保留空值和原因。

布伦特连续期货与中美利差沿用 Choice 数据接口。接收者可自行启用，配置见 [references/usage.md](references/usage.md)。未启用时这两项显示缺项。分享包只携带代码、模板和指标定义，接收者运行后自行取得数据。

阅读 [references/data-contract.md](references/data-contract.md) 后再改指标、来源、公式或摘要规则。需要排查环境、抓取或回滚问题时，阅读 [references/usage.md](references/usage.md)。

## 必须保留的口径

- 检查日、抓取时间和实际观察日分别披露。周度、季度数据保留真实频率；日期推进且数值相同仍计为新观察。
- SOFR与ON RRP利差按共同观察日计算，单位为bp。联邦基金目标区间核验最新已生效的美联储实施公告，同时保存上下限和中点。
- 数据校验、公式复算与来源日期检查通过后才能发布。结构错误或来源日期倒退时保留该栏目旧正式版本，并披露本轮未更新；其他栏目继续处理。
- 首次取得数据时，用最新两个观察点建立日度摘要；后续依据新增观察和脚本阈值更新。保留政策区间变动、EFFR越界及指定融资工具从零转正的强制事件；摘要最多3组，不生成综合打分。
- 议息概率采用 Polymarket 的交易报价。保留事件、Yes代币、报价口径和抓取时间，同一会议内比较概率变化；缺少历史时留空。
- 布伦特保留 `B.IPE` 品种标识及实际 Choice 序列 `EMM01588169`。更换数据源须同时修改来源、口径说明和校验器。

## 交付

运行只读验收，并在可用浏览器中检查页面渲染、图表切换、指标导航和导出。交付网页路径、数据检查日及真实完整性；逐项说明缺失、unavailable、partial和本轮未更新。`verified_partial` 表示页面通过发布验收且有数据缺项。

如果网络或授权限制使完整取数无法完成，交付已生成的页面和可验证的结果，写明受影响指标与原因。完整性以本轮发布清单和原始响应为准。

分享 skill 时打包整个 `kk-usd-liquidity` 文件夹，保持 `SKILL.md`、`agents`、`scripts`、`references` 和 `assets` 的相对位置。
