# 综合周报固定版式

[五页 HTML 参考模板](../templates/weekly-layout.html)可直接用浏览器离线打开。它以确认的版式为基准，示例图和文字均为占位内容。每周沿用壳和组件结构，替换日期、速读、图表、表格、来源及交互数据。仅在用户明确要求改版时更换布局。

## 页面结构

- 使用同一个 HTML 文档。桌面左侧固定侧栏，1440px 下侧栏宽 220px，正文从 x=220px 开始，内边距为 40px 36px；800px 及以下切换为顶部吸附导航，390px 下正文左右留白各 14px。
- 侧栏按宏观、港股、A股板块复盘、A股策略、美元流动性排序。无锚点默认宏观；页签和对应栏目导航同步。保留 `data-report`、`data-report-nav`、`data-report-panel` 与各栏目锚点，美元页兼容 `usd-` 和 `usl-`。禁用脚本时五页仍可阅读。
- 各页依次保留英文眉题、周报标题、实际报告区间、本周速读、编号栏目。桌面普通图卡两列，窄屏一列，卡片圆角 8px。图题与周期标签同排，截止日期集中标一次，图在上、变化条在下。
- 雾蓝珊瑚色板与字体样式直接复用模板。中文楷体，英文和数字 Arial。港股盈利宽图及行业散点在窄屏于卡内横滑；行业数据表与来源默认折叠。
- 以本周组件替换模板占位区。保留真实散点提示、排序、美元区间切换与 Excel 导出等组件脚本，并检查 ID、数据对象和事件作用域。四页兼容工具和 iframe 预览不用于交付此版式。

## 交付前验收

1. 同时打开模板与候选页，在 1440px 和 390px 对照侧栏／顶部导航、正文宽度、图卡列数、标题、字体和变化条。确认根文档具备全部五页，且整页没有横向溢出。
2. 验证默认宏观、全部页签、栏目跳转、浏览器深链、无脚本阅读；检查图内 SVG 文字边界和窄屏卡内横滑。
3. 实测行业散点和表格、来源展开、美元图表区间和 Excel 导出，并读回下载文件。核对报告周、实际观测日、缺项与图表数据，确认模板占位内容已全部替换。
